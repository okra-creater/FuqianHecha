# 付前核查 · FuqianHecha

面向大学生兼职、租房场景的规则式转账风险核查助手。工行杯拟参赛方向：金融安全服务。

## 当前阶段

当前规则版已完成透明规则分析器、已审核资料引用、开发集评测、网页输入与结果展示，以及 Docker 部署准备。分析过程不调用大模型，也没有交互式追问流程。
第一版面向香港交易场景，支持中文。港澳台是参赛区域，不代表知识库能覆盖澳门、台湾或内地规则。

- 后续：按需要加入交互式追问、动态检索和大模型增强，再进行对照评测。

## 参赛材料版本

`output/pdf/PaySentinal_ICBCCup_Submission.pdf` 是 2026-10-11 制作的历史提案，其中测试数量为当时快照，不代表当前仓库。当前规则版不包含网页测试；现存测试以 `python3 -m unittest discover -s tests -q` 的结果为准。

## 本地运行

```bash
python3 -m fuqianhecha.web
```

然后打开 `http://127.0.0.1:8000`。当前版本不需要 API Key。

## Docker 运行

```bash
docker compose up --build
```

详细说明见 [部署准备](docs/DEPLOYMENT.md)。不得复用或复制旧作业的密钥到版本库，`.env` 必须始终保持在 `.gitignore` 中。
