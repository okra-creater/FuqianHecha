# 当前规则版架构

当前实现可完成一次性文字核查。场景识别、风险规则、报告生成、已审核资料加载和网页展示均已实现；不调用大模型。

```text
CLI / web UI
        |
        v
BaselineAnalyzer ----> rules.py
        |                   |
        |                   v
        +----------> KnowledgeRepository ----> reviewed sources.json
        |
        v
AnalysisReport
```

## 模块职责

- `models.py`：统一输入输出会使用的数据结构和三种核查状态。
- `rules.py`：用透明文字规则提取候选风险信号及原文证据。
- `analyzer.py`：执行场景识别、规则匹配、状态选择和报告生成。
- `knowledge.py`：加载已审核来源；按预设的规则与来源映射提供风险引用，无风险信号时按词项匹配提供场景资料。
- `cli.py`：接收文字并输出 JSON。
- `web.py` 与 `web/`：提供分析接口和网页输入、结果展示。
- `evaluation.py` 与 `tests/`：对合成开发案例和非网页模块做自动检查。网页测试暂不设置。
